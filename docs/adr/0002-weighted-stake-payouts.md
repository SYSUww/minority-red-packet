# 少数派按人数判定，败者资金按赢家投入权重分配

玩家加入回合时选择 1～10 MON 的整数投入。最终少数派仍只按各红包的有效揭晓人数判定，投入金额不增加票数，也不改变胜负概率。

形成少数派后，每名赢家先取回自己的投入，再按“个人投入 / 全部赢家投入”分配败者资金。整数除法产生的最小单位余数按赢家报名顺序分配，保证整个回合资金池全部可领取。未揭晓玩家视为弃权，其投入计入败者资金；无法形成少数派或房间人数不足时，每名玩家取回自己的实际投入。

这一规则让投入金额只承担收益权重和损失风险，不混入少数派的人数判定，同时要求重新部署合约并更新前端 ABI。
